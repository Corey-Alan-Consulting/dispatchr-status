# Dispatchr Status

[Upptime](https://upptime.js.org)-powered uptime monitor and status page for
[Dispatchr](https://dispatchr.social), served at
[status.dispatchr.social](https://status.dispatchr.social).

Monitoring runs on GitHub Actions (see `.upptimerc.yml` for the checked
endpoints); the static status page deploys to Cloudflare Pages. This README is
regenerated automatically on the first successful run.

See [`MAINTENANCE.md`](./MAINTENANCE.md) for the customizations (GitHub-App auth
and the Cloudflare Pages deploy) that differ from a stock Upptime install.
